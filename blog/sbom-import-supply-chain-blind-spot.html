Building a CTI Platform From Scratch (9 of 10)

2026-11-25

SBOM Import and the Supply Chain Blind Spot

Every vulnerability pipeline I had built up to this point assumed I already knew what software I was running. That assumption breaks down fast once you account for dependencies, the libraries your application pulls in that nobody explicitly chose, that update silently, and that can carry a critical vulnerability into your environment without a single line of your own code changing.

The platform accepts CycloneDX formatted software bills of materials, the standard format for describing exactly what components, including transitive dependencies, make up a piece of software. Importing an SBOM turns a vague sense of "we use this application" into a precise list of every package and version inside it, which then feeds the same asset matching logic the rest of the platform already runs. A CVE affecting a logging library three dependencies deep gets caught the same way a CVE affecting the application itself does.

This is the part of vulnerability management that gets skipped most often, not because it is technically hard, but because it is tedious and the payoff is invisible until the one time it matters. Nobody gets credit for the supply chain compromise that did not happen because an SBOM import caught a vulnerable dependency before it shipped. You only hear about the ones that were not caught. That asymmetry is exactly why so many organizations treat SBOM tracking as a compliance checkbox rather than an operational practice, generate the document once for an audit and never look at it again.

Building the import pipeline taught me how much easier it is to generate an SBOM than to keep one current. A snapshot from six months ago tells you what was true six months ago. The value is almost entirely in treating it as a living input, re-ingested whenever a build changes, not a static artifact you produce once and file away. That is a process discipline problem as much as a technical one, and it is the piece of this platform I am least satisfied with so far, the ingestion works, the discipline to keep it current is still a work in progress.
