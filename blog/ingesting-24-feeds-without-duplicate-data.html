Building a CTI Platform From Scratch (2 of 10)

Ingesting 24 Feeds Without Drowning in Duplicate Data

The platform runs 24 separate ingestion jobs on their own schedules, CISA KEV, VulnCheck KEV, NVD, GitHub Advisories, ThreatFox, MalwareBazaar, URLhaus, SSLBL, Spamhaus, OTX, EPSS, CWE mappings, Sigma rules, HIBP exposure checks, passive DNS, honeypot hits, and a handful of security news RSS feeds. Most of them write into their own table. The ones that overlap are where it gets interesting.

CISA's Known Exploited Vulnerabilities catalog is the clearest example. I had five different pieces of code that each touch KEV data: one pulls the raw CISA catalog, one enriches entries with MITRE ATT&CK mappings, one cross-references VulnCheck's broader exploited-vulnerability list, one does CVSS backfill, one tracks how fast new entries get added. Each one was writing rows into the same vulnerabilities table, and each one, independently, decided to label its own rows with a slightly different source string. CISA KEV. cisa-kev. kev. VulnCheck-KEV. A fifth variant in mixed case from an older version of the code that never got cleaned up.

Nobody designed that on purpose. It happened the way most data fragmentation happens, five scripts written at five different times, each one reasonable on its own, none of them aware the other four existed.

The cost was not obvious until I built a freshness dashboard to tell me when a feed had gone stale. The dashboard grouped rows by source and checked how recently each group had been updated. Because CISA only adds a handful of new KEV entries most weeks, whichever of the five scripts happened to insert a given CVE first got credit for being fresh, and the other four looked permanently dead. I had a monitoring system that was technically correct and completely misleading, flagging four healthy pipelines as broken because they were splitting credit for the same handful of CVEs.

The fix was not touching five scripts across two hosts. It was collapsing the labels at query time, one canonical source name for everything that is obviously the same underlying feed, and letting the real ingestion code stay exactly as fragmented as it already was. Sometimes the right fix is not the one that looks most thorough.
