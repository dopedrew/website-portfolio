Building an Attack Map From My Own Honeypot Traffic

I built a world map that plots where honeypot traffic originates against where my own perimeter gets probed, an SVG rendering with no external mapping library, fed directly from a table of honeypot hits and a table of real attack origins. It is a genuinely satisfying piece of engineering. It is also, right now, mostly empty, and the reason why taught me more than the map itself did.

The honeypot sits behind a Cloudflare WAF, because an unprotected honeypot on the open internet is a bad idea for reasons that have nothing to do with the research value of the data it collects. The problem is that the WAF does its job well. Most of the scanning and exploitation traffic that would otherwise hit the honeypot gets filtered before it ever arrives. The honeypot currently shows 97 recorded hits total, which is a small number for a system that has been running for months, and the gap is not a bug, it is my own defense working exactly as designed.

This is a more useful lesson than a rich dataset would have been. A system built to observe attacker behavior and a system built to block attacker behavior are in direct tension with each other, and you cannot optimize both at once without a deliberate tradeoff. Security researchers who run honeypots at scale either accept a higher baseline risk by running with lighter protection, or they build separate, carefully isolated infrastructure specifically for the collection that never touches anything they actually need to defend. I did neither. I bolted a honeypot onto infrastructure that is primarily meant to protect production systems, and the natural consequence is a honeypot that does not see much.

The map is still worth having, because the small number of real hits it does capture are worth visualizing well, and because the architecture is already there if I decide the research value justifies rearchitecting the exposure. But the honest version of this post is not "look at my attack map." It is: I built a data collection system and then put my best defenses directly in front of it, and now I know exactly why that tradeoff exists instead of assuming it does not apply to me.
